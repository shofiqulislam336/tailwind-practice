# Netflix Front Page

## About the Project
This project is a simple Netflix UI clone created using **Tailwind CSS**. The goal of this project is to practice styling and recreate the look of Netflix's screen using Tailwind CSS.

## Built With
- HTML
- Tailwind CSS

## Features
- Netflix-inspired user interface
- Styled using Tailwind CSS utility classes
- Movie and TV show poster images
- Simple and clean layout


## What I Learned
- Using Tailwind CSS utility classes
- Styling layouts, colors, spacing, and typography
- Recreating an existing website design for practice
